claude-config 저장소는 Claude를 규칙적으로 만들기 위한 것이다. 그 안에서 정한 규칙(저장소 CLAUDE.md, docs/versioning.md, drafts/README.md, PROGRESS 머리말)을 Claude가 편의상 어기면 목적 자체가 무너진다.

**Why:** 2026-09-09 사용자: "규칙적이지 않기 때문에 Claude 설정을 하는 것이므로 정의된 규칙에서는 벗어나지 않도록, 벗어나야 된다면 찾아보고 검토해보자." 직전에 승격마다 릴리즈 컷을 제안해 "모이면 컷" 규칙을 어긴 일([[feedback-release-cadence]])이 계기.

**How to apply:** 규칙과 다른 행동이 필요해 보이면 멈춘다 → 근거(공식 문서·커뮤니티·실제 사고) 조사 → 제안 → 승인 → 규칙 문서 수정 → 진행. 순서를 바꾸지 않는다.
