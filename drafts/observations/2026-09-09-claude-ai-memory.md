## 활용

1. **C-20 사업기획 스킬 요구사항이 절반은 나왔다.** 웹 메모리가 말하는 산출물: 구조화된 기획 문서(제품 범위·경쟁 분석·수출 방식 같은 결정 항목), 경쟁 분석 표(카테고리별), 인력·일정 견적(표). 스킬은 "이 셋 중 무엇을, 어떤 틀로"를 묻고 시작하면 된다. 제품 세부는 스킬에 넣지 않는다(저장소 무관 스킬 원칙).
2. **웹 메모리 정정(사용자, Settings → Memory)**: `claude-setup`의 경로를 `base/`·`tools/`·`install.sh`로 고치거나, 그 항목을 지우고 "구조는 저장소 README 참조"로 바꾼다. 웹은 GitHub 커넥터로 저장소를 읽을 수 있으니 세부를 메모리에 둘 필요가 없다.
3. **프로필 보강(사용자)**: "개발자가 아님, 한국어, 결론 먼저 짧게, 프로젝트마다 스택 다름"을 profile에 추가하면 웹 답변도 Claude Code와 같은 톤이 된다. 전역 지침 §1·§2와 같은 내용.
4. 로컬 메모리(`user_profile.md`)에 "웹은 사업기획 용도, 제품 카테고리" 한 줄 추가함.
