# 관찰 2026-09-12 — claude-config 세션(Windows)

## 요청 방식

- "다음 진행해야되는 것 추천해줘" → "github 재확인해줘" → "진행해줘". 추천을 받은 뒤 **원격 상태부터 재확인**시킴. 기기를 오가며 쓰므로 로컬 문서가 낡았을 수 있다는 감각이 있다.

## 교정

- 세션 시작에 HANDOFF·PROGRESS만 읽고 추천했더니 로컬이 원격보다 14커밋 뒤였고 추천이 전부 낡은 것이었다. **세션 시작 시 `git fetch` + behind 확인을 HANDOFF 읽기보다 먼저** 해야 한다. 여러 기기를 쓰는 저장소는 로컬 문서가 원본이 아니다.
- HANDOFF "다음 할 일"이 완료 항목을 가리키는 문제가 09-09에 이어 두 번째. 이번엔 "v0.5.0 컷 직후"라는 시점 의존 표현이 v0.6.0 뒤에도 남아 있었음.

## 작업

- Windows `install.sh` 재실행 → v0.6.0 일치. dry-run 먼저 보고 실제 실행하는 순서가 자연스러움.
