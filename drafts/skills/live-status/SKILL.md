# live-status

`claude agents --json`(공식 인터페이스)을 몇 초마다 읽어 세션 카드를 실시간으로 갱신하는 이 PC 전용 화면이다. 화면을 보는 데는 토큰이 들지 않는다.

## 0. 시작 전 확인

- 명령은 전부 이 스킬 폴더의 `scripts/live.sh`로 실행한다
  - 경로는 스킬을 불러올 때 안내되는 base directory 기준(`bash "<스킬 폴더>/scripts/live.sh" <명령>`).
- 먼저 `live.sh status`로 켜져 있는지 보고 한 줄로 알린다.
- Windows·Mac에서 쓴다. 화면 없이 쓰는 Linux 서버에서는 켜지 않고 `claude agents`(터미널 화면)를 안내한다.

## 1. 요청별 절차

| 요청 | 명령 | 할 일 |
| --- | --- | --- |
| 켜기·보여줘 | `start` 뒤 `open` | 서버를 띄우고 기본 브라우저로 연다 |
| VS Code에서 보기 | `start` 뒤 `url` | 주소를 클립보드에 복사하고 "명령 팔레트에서 Open Integrated Browser를 열어 붙여넣기"를 안내한다 |
| 끄기 | `stop` | 서버를 끈다 |
| 상태 | `status` | 켜짐 여부와 주소 |

## 2. 화면에서 볼 수 있는 것

- 세션마다 카드 하나: 이름, 폴더 이름, 상태, 시간
  - 상태는 색만이 아니라 모양과 글자를 함께 쓴다(▶ 작업 중, ⏸ 쉬는 중, ■ 끝남, ? 확인 불가).
  - 시간은 "이번 요청 N분째"와 "세션 시작 후 N시간". 화면을 켜기 전부터 작업 중이던 세션은 이번 요청의 시작 시각을 모르므로 "이 화면을 켠 뒤 N분째"로 표시한다.
- 맨 위에 작업 중·쉬는 중·끝남 개수. 브라우저 탭 제목에도 작업 중 개수가 나온다.
- 문제가 있으면 화면 위에 빨간 줄로 이유를 보인다: 서버에 연결 안 됨, claude를 못 찾음, 목록을 못 읽음, 갱신이 멈춤.

## 3. 알아둘 한계

- 서브에이전트는 `claude agents --json` 출력에 없어서 표시하지 않는다.
- 세션이 목록에서 사라지면 15분 동안 "끝남"으로 남긴다. 비정상 종료와 정상 종료는 구분하지 못한다.
- `claude agents`는 research preview라 출력 형식이 바뀌면 "목록을 읽지 못함"이 나올 수 있다. 그때는 이슈로 알린다.
- 대화 내용과 전체 경로는 읽지도 보여 주지도 않는다. 서버는 127.0.0.1에만 열리고 다른 이름으로 들어온 요청은 거부한다.

## 하지 않는 것

- 알림을 보내지 않는다([Issue #5](https://github.com/yanos0218/AI/issues/5) 보류).
- 사용량 기록은 이 스킬이 아니라 `usage-dashboard`가 맡는다.
