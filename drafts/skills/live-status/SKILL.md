# live-status

세션은 `claude agents --json`(공식 인터페이스), 서브에이전트는 Claude Code가 남기는 기록 파일에서 읽어 몇 초마다 갱신하는 이 PC 전용 화면이다. 화면을 보는 데는 토큰이 들지 않는다.

## 0. 시작 전 확인

- 명령은 전부 이 스킬 폴더의 `scripts/live.sh`로 실행한다
  - 경로는 스킬을 불러올 때 안내되는 base directory 기준(`bash "<스킬 폴더>/scripts/live.sh" <명령>`).
- 먼저 `live.sh status`로 켜져 있는지 보고 한 줄로 알린다.
- Windows·Mac에서 쓴다. 화면 없이 쓰는 Linux 서버에서는 켜지 않고 `claude agents`(터미널 화면)를 안내한다.

## 1. 요청별 절차

| 요청 | 명령 | 할 일 |
| --- | --- | --- |
| 켜기·보여줘 | `start` 뒤 `open` | 서버를 띄우고 기본 브라우저로 연다 |
| VS Code에서 보기 | `start` 뒤 `url` | 주소를 클립보드에 복사하고 "명령 팔레트에서 Open Integrated Browser를 열어 붙여넣기"를 안내한다 |
| 끄기 | `stop` | 서버를 끈다 |
| 상태 | `status` | 켜짐 여부와 주소 |

## 2. 화면에서 볼 수 있는 것

- 맨 위: 한 문장 요약("작업 중 · 세션 1개 · 서브에이전트 4개", 없으면 "지금 돌고 있는 작업이 없습니다")과 숫자 타일 넷
  - 작업 중인 세션, 서브에이전트 진행, 가장 오래 걸리는 중인 것, 오늘 실사용 토큰(메인과 서브에이전트로 나눔, 최근 5시간 포함).
  - 오른쪽 위에 "실시간 · N초 전 갱신" 표시. 끊기면 "연결 확인 필요"로 바뀌고 이유가 빨간 줄로 나온다.
- 지금 진행 중: 세션 카드 아래에 일하는 서브에이전트 카드가 연결선으로 이어진다. 쉬는 중이어도 서브에이전트가 일하면 여기에 올라온다.
- 쉬는 중: Claude가 응답을 끝내고 내 입력을 기다리는 세션을 한 줄씩.
  - 방금(2분 안) 끝난 세션이나 서브에이전트는 "✓ 내 차례"·"방금 끝남"으로 강조하고, 탭 제목과 아이콘에도 상태가 나온다.
  - 토큰은 만·억 단위로 usage-dashboard와 같게 쓴다.
- 최근 끝난 것: 접어 둔 목록(개수만 보임). 타임라인: 최근 30분 가로 막대로 겹침을 본다.
- 상태는 색만이 아니라 모양과 글자를 함께 쓴다(▶ 작업 중, ◔ 조용함, ⏸ 쉬는 중, ■ 끝남, ? 확인 불가).
- 사용량 대시보드 →: 기존 usage-dashboard 화면을 같은 주소 아래 `/usage/`로 그대로 연다(맨 위에 실시간 현황으로 돌아가는 줄만 추가). 사용량 기록을 켜 둔 경우만 동작한다.

## 3. 알아둘 한계

- 서브에이전트 정보는 문서화되지 않은 파일 형식에서 읽는다(`<설정 폴더>/projects/<프로젝트>/<세션 ID>/subagents/`). Claude Code가 바꾸면 "기록을 읽지 못함" 줄이 나올 수 있다. 읽기 전용이고 기록은 첫 줄만 연다.
- 서브에이전트의 상태는 추정이다. 마지막 활동이 90초 안이면 작업 중, 10분을 넘으면 끝남(추정, 줄무늬 막대). 그 사이는 "조용함"이며 도구를 오래 실행하는 중일 수 있어 멈춤으로 단정하지 않는다.
- 토큰은 usage-dashboard의 시간별 집계(`usage-log/hourly.json`)를 읽는다. 토큰을 다시 계산하지 않고, 응답이 끝날 때마다 갱신되므로 응답 도중에는 늘지 않는다.
- 에이전트 팀과 배경 셸 명령은 아직 표시하지 않는다.
- 이 화면은 대화 내용과 전체 경로를 읽지도 보여 주지도 않는다. 작업 제목은 보이며 `LIVE_SHOW_TITLES=0`으로 숨긴다. 단 `/usage/` 화면에는 요청 내용 일부가 들어 있어 `LIVE_SHOW_USAGE=0`으로 토큰 타일과 함께 끈다.
- 서버는 127.0.0.1에만 열리고 다른 이름으로 들어온 요청은 거부한다. `/usage/`는 화면 파일 두 개만 내보낸다.
- `claude agents`는 research preview라 출력 형식이 바뀌면 "목록을 읽지 못함"이 나올 수 있다. 그때는 이슈로 알린다.

## 하지 않는 것

- 알림을 보내지 않는다([Issue #5](https://github.com/yanos0218/AI/issues/5) 보류).
- 사용량 기록과 분석은 이 스킬이 아니라 `usage-dashboard`가 맡는다(여기서는 요약을 읽고 화면을 연결할 뿐).
