# usage-dashboard

토큰 사용 기록을 켜고 끄고, 대시보드를 연다. 기록과 화면은 로컬 파일이라 보는 데 토큰이 들지 않는다.

## 0. 시작 전 확인

- 이 스킬 폴더의 `scripts/usage.sh`를 쓴다(스킬을 불러올 때 안내되는 base directory 기준).
- 먼저 `bash "<스킬 폴더>/scripts/usage.sh" status`로 켜짐 여부와 기록 기간을 확인해 한 줄로 알린다.
- 대상은 Windows·Mac이다. UI 없이 쓰는 Linux 서버에서는 켜지 않는다(2026-09-27 결정).

## 1. 요청별 절차

| 요청 | 할 일 |
| --- | --- |
| 켜기 | ★ 사용자 확인 ★ 뒤 `usage.sh enable`. 남아 있는 대화 기록(기본 30일 보관)을 한 번 훑어 채운다<br>켠 뒤 자동 기록은 설정의 Stop 훅이 맡는다. 훅이 등록돼 있지 않으면 그렇게 알리고 멈춘다 |
| 열기·보여줘 | `usage.sh open`. 대시보드를 다시 만들고 브라우저로 연다 |
| VS Code에서 보기 | `usage.sh serve`. 이 PC 전용 주소(127.0.0.1)로 띄우고 주소를 클립보드에 복사한다<br>사용자에게 "Ctrl+Shift+P → 통합 브라우저 열기(Open Integrated Browser) → 주소창에 붙여넣기"를 안내한다<br>데스크톱 VS Code는 Simple Browser 명령이 숨겨져 있다. 끄기는 `usage.sh stop` |
| 지금 갱신 | `usage.sh render` |
| 끄기 | ★ 사용자 확인 ★ 뒤 `usage.sh disable`. 쌓인 기록은 지우지 않는다 |
| 기록 삭제 | 스크립트로 하지 않는다. 기록 폴더 경로만 알려 주고 사용자가 지우게 한다 |

## 2. 알아 둘 것

- 저장 위치는 `~/.claude/usage-log/`다. 설정 업데이트(`install.sh`)는 이 폴더를 건드리지 않아 기록이 유지된다.
- 시간 단위 합계와 세션 시작 크기는 영구 보관, 요청별 기록과 큰 도구 결과는 90일 보관한다.
- 요청은 어떤 작업이었는지 알아보도록 첫 80자만 저장한다. 파일 내용·명령 출력은 저장하지 않는다.
- 5시간 블록은 첫 사용 시각(정시)부터 5시간으로 나눈 추정이라 실제 한도 창과 다를 수 있다. 한도 대비 사용률은 /usage(VS Code는 계정·사용량 창)에서 본다.
- 화면에서 기간(시간·일·월), 기준(전체/캐시 제외), 나눠 보기(누가/모델)를 고를 수 있다. 캐시 재사용분은 요금이 일반 입력의 약 10%라 "캐시 제외"가 실제 부담에 더 가깝다.
- 세션 여러 개가 동시에 끝나도 잠금으로 한 번에 하나씩 기록한다.
- 켜기 전 사용분은 Claude Code가 남겨 둔 대화 기록만큼만 채울 수 있다(`cleanupPeriodDays` 기본 30일).
- 기기마다 따로 쌓인다. 여러 기기를 합쳐 보지 않는다.
- 계정 전체 한도 사용률은 이 대시보드가 아니라 `/usage`에서 본다.
