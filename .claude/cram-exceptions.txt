# tools/check-cram.sh 예외 목록. 한 줄에 하나, 크램으로 오탐된 줄의 정확한(trim된) 텍스트.
# `tools/check-cram.sh --add-exception <file> <line>`로 등록한다.
# 쌓이는 예외에서 공통 패턴이 보이면(예: 특정 필드명 반복) docs-format.md 예외 규칙이나
# 이 스크립트의 휴리스틱에 반영할 후보로 검토한다(월 점검 항목, Issue #99).
- "필드명: 값" 구조화된 기록(조사 이슈 등)은 예외로 유지
- 목록 항목이 "(N) 설명A — 설명B"처럼 한 줄에 길게 늘어지면 본문 줄 + 하위 bullet으로 나눠 쓰는 규칙 추가
