# 이슈 작성 형식

라벨 하나 = 형식 하나. 라벨을 먼저 정하고 그 형식대로 쓴다.

## 라벨 매핑

| 라벨 | 용도 |
| --- | --- |
| `task` | 개발 작업, 제안·아이디어 |
| `bug` | 버그<br>동작은 하지만 의도와 다름 |
| `error` | 에러<br>실행 실패·예외·크래시로 동작 자체가 깨짐 |
| `research` | 조사 |

혼합 케이스(예: 조사에서 파생된 할 일)는 라벨을 겹쳐 붙이지 않고 **sub-issue로 연결**한다(`gh issue create --parent <원본번호>` / `gh issue edit <원본번호> --add-sub-issue <파생번호>`).

## 개발 (`task`)

```markdown
## 배경
## 작업 내용
## 검증
```

- "결과"는 본문 섹션으로 두지 않는다
  - 작업 전엔 채울 수 없다. 대신 **닫을 때 코멘트**에 남긴다: 커밋 해시(또는 PR 번호) + 실행한 검증 명령과 결과.
- 여러 세션에 걸치면 작업할 때마다 댓글로 진행 상황을 남긴다(끝나고 요약 하나만 쓰지 않는다).

## 버그 (`bug`) · 에러 (`error`)

같은 구조를 쓴다. 원인 없이 증상만 적지 않는다 — 이유 없이 일어나는 결함은 없다.

```markdown
## 증상
## 재현
## 원인
## 영향
## 수정 이력
```

- 선택: 첨부(에러 로그·스크린샷)
  - `error`는 로그가 나오는 게 보통이라 **필수**, `bug`는 선택.
- 선택: 환경 정보(OS·버전 등, 필요할 때만).

## 조사 (`research`)

```markdown
## 조사
- 질문: 무엇을 알고 싶었나
- 결론: 한 문단
- 조사일: YYYY-MM-DD
- 출처: 링크 + 무엇을 직접 실행해 확인했는지
- 영향: 이 결론이 바꾼 문서·설정
```

- 새 조사 전에 `gh issue list --label research --state all --search "<키워드>"`로 먼저 찾아본다.
- 조사일이 오래됐으면(기본 90일, Claude Code 기능 관련은 30일) 재조사하고 같은 이슈에 댓글로 갱신한다(새 이슈를 만들지 않는다).

## 제안·아이디어 (`task`)

아직 채택 여부가 안 정해진 것 — "개발"과 달리 할 일로 확정되지 않았다.

```markdown
## 배경
## 제안 내용
## 기대 효과
## 결정
```

- "결정"은 채택/기각/보류 + 이유. 본문에 빈 칸으로 만들어 두고, 닫을 때 채운다.

## 이슈 수명 관리

- 하나의 목표에 커밋이 여러 개 필요해도 이슈 하나를 계속 쓴다
  - 커밋마다 새 이슈를 열지 않는다
    - 커밋 메시지엔 기존 이슈 번호만 적으면 된다(`pre-commit-check.sh`도 새 이슈를 요구하지 않고 번호 하나면 통과시킨다).
  - 진행 상황은 코멘트로 남기고, 목표 전체가 끝났을 때만 닫는다.
- 작업 중 원래 범위 밖의 것이 발견되면(파생 작업) 새 이슈를 열어 sub-issue로 연결한다
  - 새로 만들 때: `gh issue create --parent <원본번호>`.
  - 이미 만들어 둔 이슈를 나중에 엮을 때: `gh issue edit <원본번호> --add-sub-issue <파생번호>`("Add existing issue").
  - 평행한 별도 이슈로 그냥 두지 않는다.
- 이슈 본문에 "Issue #N에서 파생/이어서/후속" 같은 표현으로 다른 이슈를 언급하는 순간 바로 연결한다
  - 나중으로 미루면 놓친다(2026-09-14, #65~#93 계열에서 15건 소급 발견). 언급하는 그 자리에서 `--add-sub-issue`까지 끝낸다.
- 완전히 무관한 새 요청일 때만 새 이슈를 연다.

## 공통

- 목록 항목·표 셀에서 주어와 설명을 `—`나 `:`로 이어쓰지 않는다([base/rules/docs-format.md](../base/rules/docs-format.md)).
- 완료해서 닫을 때 커밋에 `Closes #N`을 쓰면 자동으로 닫힌다.
- **제목은 마크다운을 렌더링하지 않는다.** 백틱·`**`·`[]()` 등을 쓰면 기호가 그대로 보인다
  - 파일·명령어를 제목에 넣을 땐 기호 없이 그대로(예: `` `tools/pack.sh` `` 대신 `tools/pack.sh`).
