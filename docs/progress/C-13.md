# C-13 dev-workflow 스킬 — 요구사항 결정과 시험 기록

2026-09-09 사용자 답변으로 세 가지가 정해져 SKILL.md 초안을 썼고, 같은 날 3시나리오 발동 시험을 통과했다(2026-09-09 사용자 승인으로 `base/skills/`에 승격, Windows 설치, `[Unreleased]`). 시험은 각 시험 저장소의 `.claude/skills/dev-workflow/`에 초안을 넣고 `claude -p` 새 세션으로 실행.

| 항목 | 결정 |
| --- | --- |
| 발동 문구 | "테스트 어떻게 해?", "테스트 방법 정리해줘", "테스트 규칙 만들어줘", "파일 정리해줘", "폴더 구조 잡아줘", "이 파일 어디에 둬야 해?", "테스트 돌리고 결과 보여줘". 릴리즈·배포는 제외(dev-release·저장소 배포 스킬) |
| 산출물 / 결과물 | **산출물** = 과정 중 생기는 것(테스트 문서, 구조표, 테스트 파일, CI 잡) → 저장소에 남긴다. **결과물** = 최종 전달되는 성과(검증된 기능·문서) → 증거(명령·출력)와 함께 보고한다. 스킬은 둘 다 다룬다 |
| 파일 관리 | **파일** = 실제 데이터가 든 개별 자료, **폴더** = 파일·하위 폴더를 담는 공간. 따라서 "파일 관리" = 구조 표준(무엇이 어디에), 이름 규칙, 정리(이동·삭제는 확인 후) |
