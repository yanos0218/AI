# 서브에이전트 운용 세부 규칙

전역 `CLAUDE.md` §5에서 옮겨 온 규칙. 서브에이전트를 띄우기 전에 읽는다.

- 전용 에이전트가 있으면 그것을 쓴다(조사 `researcher`, 문서·참조 점검 `auditor`, 검사 실행 `verifier`). 에이전트 파일에 모델이 정해져 있으면 `model` 값을 넘기지 않는다. (2026-09-27, 이 문장이 "Sonnet으로"뿐이라 메인이 verifier의 Haiku 지정을 덮어쓴 사례)
- 그 밖의 서브에이전트와 시험 세션은 Sonnet으로.
- 여러 서브에이전트에 병렬로 위임할 때는 서로 겹치지 않는 파일 집합을 배정한다(겹치면 나중에 끝나는 쪽이 먼저 것을 덮어쓴다).
