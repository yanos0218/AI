# usage-dashboard

토큰 사용 기록을 켜고 끄고, 대시보드를 연다. 기록과 화면은 이 PC의 파일이라 보는 데 토큰이 들지 않는다.

## 0. 시작 전 확인

- 명령은 전부 이 스킬 폴더의 `scripts/usage.sh`로 실행한다
  - 경로는 스킬을 불러올 때 안내되는 base directory 기준(`bash "<스킬 폴더>/scripts/usage.sh" <명령>`).
- 먼저 `usage.sh status`로 켜짐 여부와 기록 기간을 보고 한 줄로 알린다.
- Windows·Mac 전용이다
  - 화면 없이 쓰는 Linux 서버에서는 켜지 않고 `/usage`를 안내한다.

## 1. 요청별 절차

| 요청 | 명령 | 할 일 |
| --- | --- | --- |
| 켜기 | `enable` | ★ 사용자 확인 ★ 뒤 실행<br>남아 있는 대화 기록(기본 30일 보관)을 한 번 훑어 채운다. 처음엔 수십 초 걸릴 수 있다<br>켠 뒤 자동 기록은 Stop 훅이 맡는다. 훅이 등록돼 있지 않으면 등록 방법(`references/setup.md`)을 알리고 멈춘다 |
| 열기·보여줘 | `open` | 화면을 다시 만들고 기본 브라우저로 연다 |
| VS Code에서 보기 | `serve` | 이 PC 전용 주소(127.0.0.1:8765)로 띄우고 주소를 클립보드에 복사한다<br>"Ctrl+Shift+P(Mac은 Cmd+Shift+P) → 통합 브라우저 열기(Open Integrated Browser) → 주소창에 붙여넣기"를 안내한다<br>다 보면 `stop`으로 끈다 |
| 지금 갱신 | `render` | 화면만 다시 만든다. 브라우저는 새로고침 |
| 상태 | `status` | 켜짐 여부, 기록 기간 |
| 끄기 | `disable` | ★ 사용자 확인 ★ 뒤 실행. 쌓인 기록은 지우지 않는다 |
| 기록 삭제 | 없음 | 스크립트로 지우지 않는다. 기록 폴더 경로(`~/.claude/usage-log/`)만 알려 주고 사용자가 지우게 한다 |

- `enable`·`disable`은 허용 목록에 넣지 않았다. 실행할 때 권한 확인 창이 한 번 더 뜨는 게 정상이다.

## 2. 화면에서 볼 수 있는 것

- 기간
  - 5시간 블록·시간·일·월·요일×시간.
- 기준
  - 실사용(캐시 재사용분 제외)과 캐시 포함. 캐시 재사용분은 요금이 일반 입력의 약 10%라 실사용이 실제 부담에 더 가깝다.
- 나눠 보기
  - 저장소, 누가(메인/서브에이전트), 모델.
- 요청 순위와 상세
  - 많이 쓴 요청, 원인 단서, 요청 원문·도구 호출 흐름.
- 5시간 블록은 첫 사용 시각(정시)부터 5시간씩 나눈 추정이다
  - 실제 한도 창과 다를 수 있다. 한도 대비 사용률은 `/usage`(VS Code는 계정·사용량 창)에서 본다.

## 3. 세부 자료

- 설치·훅 등록·폴더 구조·저장 파일·보관 기간·문제 해결은 `references/setup.md`
  - 훅이 안 도는 것 같거나, 기록이 비거나, 포트가 겹치거나, 사용자가 "어디에 뭐가 저장돼?"라고 물을 때 읽는다.

## 하지 않는 것

- 기록 파일을 지우거나 고치지 않는다. 삭제는 사용자가 직접 한다.
- serve를 127.0.0.1 밖으로 열지 않는다. 요청 원문 일부가 들어 있다.
- 여러 기기 기록을 합치지 않는다. 기기마다 따로 쌓인다.
